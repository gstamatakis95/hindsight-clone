# CCR WP-24-1: depguard rules keep Datadog out of engines, domain and ports

**Requested by:** WP-24 (optional Datadog observability, decision 2400).

**Change:** `.golangci.yml` gains add-only depguard rules; nothing else under a frozen path changes.
- **engines:** a new deny entry for `github.com/DataDog`.
- **domain:** a new deny entry for `github.com/DataDog`.
- **port:** a new rule covering `**/internal/port/**` that denies `github.com/DataDog`.

No existing rule, linter setting or formatter changes.

**Impact:**
- Lint is stricter only for imports nobody makes today. The Datadog SDK stays confined to
  `internal/observability`, which is wired in `cmd/memd`.
- No API, port, domain or schema change. `buf breaking` is unaffected.

**Ruling:** APPROVED by the orchestrator (2026-10-11), limited to the add-only depguard entries above.
