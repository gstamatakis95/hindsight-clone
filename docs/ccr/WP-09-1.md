# CCR WP-09-1 — Recall reads on port.Reader

**Status: PROPOSED**

## Problem
Recall must serve fuzzy tag leaves (TagLeaf.RESOLVE_FUZZY), include.chunks, include.entities and
Memory.stale. `port.Reader` "holds every query the API path needs", but it has no tag vocabulary, chunk,
entity-state or per-scope staleness read.

WP-09 consumes the first three through `recall.Lookups` (decision 902). Its methods have exactly the
signatures below, so the real reader drops in once these are implemented.

## Proposed diff (internal/port/store.go, Reader)
```diff
 type Reader interface {
 	...
 	BankSeq(ctx context.Context, b BankRef) (int64, error)
+	// BankTags returns the distinct tags of the bank's live units, most used first (ties by name).
+	BankTags(ctx context.Context, b BankRef) ([]string, error)
+	// GetChunks returns the bank's chunks with the given ids, in the order of ids; unknown ids are skipped.
+	GetChunks(ctx context.Context, b BankRef, ids []ChunkID) ([]domain.Chunk, error)
+	// EntityStates returns every entity attached to any of units, each with the ids of the live
+	// observations attached to it, ordered by entity id.
+	EntityStates(ctx context.Context, b BankRef, units []UnitID) ([]domain.EntityState, error)
+	// StaleScopes returns those of scopes that still have a live fact with consolidated_at and
+	// consolidation_failed_at unset whose tags contain the scope's tags (Memory.stale).
+	StaleScopes(ctx context.Context, b BankRef, scopes []ScopeKey) ([]ScopeKey, error)
 }
```

Postgres implementation sketch:
- **BankTags:** `SELECT unnest(tags) t, count(*) ... GROUP BY t ORDER BY count DESC, t`.
- **GetChunks:** chunks by id.
- **EntityStates:** unit_entities joined to observation units.
- **StaleScopes:** the existing Unconsolidated predicate.

The fake mirrors all four. A porttest suite covers ordering, unknown ids and tenant isolation.

## Affected WPs
- **WP-09:** recall wires `Lookups` from `port.Reader` with no code change, since the signatures match. A
  small follow-up fills `Memory.Stale` from StaleScopes.
- **WP-01 / WP-02 follow-up:** implement the methods in Postgres and the fake, plus porttest.
- **WP-13:** `ListTags` can share the BankTags query. It needs counts and paging, so it will likely be its
  own method.
- **WP-14:** pass `store.Read()` as `RecallerDeps.Lookups`.
