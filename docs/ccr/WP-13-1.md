# CCR WP-13-1 — Reader methods for listings, stats and citations, and `Unit.Stale`

**Status: PROPOSED** (WP-13).

## Problem
Several RPCs WP-13 serves need reads that `port.Reader` does not have:

| RPC / job | Missing read | SPEC lines |
|---|---|---|
| GetMemory (archived units too); restore after an entity prune | one unit, live or archived (archived: snapshot entity names) | Curation: "`ListMemories` reads both tables" |
| ListMemories | keyset listing over memory_units + memory_units_archive with filters | gRPC ListMemoriesRequest; Behavioural rules: "`ListMemories` returns no total" |
| GetObservationHistory | observation_versions rows | Curation: "Observation history comes from an `observation_versions` table" |
| GetBankStats | indexed COUNTs | Behavioural rules: "Stats and tag counts come from indexed `COUNT` queries" |
| ListTags | tag counts per source | gRPC ListTagsRequest / TagSource |
| ListDocuments | document listing with unit counts | gRPC ListDocumentsRequest |
| ListScopes, ClearObservations count | scopes with observation / unconsolidated counts | gRPC ListScopesRequest / ScopeInfo |
| ExportBankTemplate | the bank's mental-model specs | gRPC BankTemplate.mental_models |
| UpdateMemory invalidate | models whose `source_ids` cite a set of units | Curation: "a refresh of every model whose `source_ids` include the unit or a deleted observation" |
| maintenance tick | banks with unconsolidated units (worker.ConsolidationCandidates, decision 502) | Jobs: "enqueue consolidation for banks with unconsolidated units" |
| ListMemories / GetMemory | `Memory.stale` for observations | gRPC Memory.stale ("observation with unconsolidated facts in its scope") |

WP-13 declares each read as a consumer interface in its own package whose method is exactly the proposed
`port.Reader` method (same name, parameters, results), and tests against in-package stubs. Once this CCR is
applied, `port.Reader` satisfies every one of them with no glue; the query and cursor types move to
`port` and the engine packages keep aliases (`type UnitQuery = port.UnitQuery`).

## Proposed diff

### `internal/domain/unit.go`
```diff
 	// EditedAt is set by a curation edit.
 	EditedAt *time.Time
+	// Stale is set by readers on an observation when a live unit in its scope still waits for
+	// consolidation (consolidated_at and consolidation_failed_at unset); always false for facts.
+	Stale bool
```

### `internal/port/store.go` (`Reader`)
```go
	// GetUnit returns one unit of b, live (State valid) or archived (State invalidated), with Entities,
	// SourceIDs and, for observations, Stale filled; for an archived unit Entities are the names in its
	// archive snapshot (entities_snapshot), even when the entity rows were pruned since. Unknown =
	// domain.ErrNotFound. An unknown or tombstoned bank is domain.ErrNotFound.
	GetUnit(ctx context.Context, b BankRef, id UnitID) (domain.Unit, error)
	// ListUnits returns up to q.Limit units matching q, newest first (created_at, then id, both
	// descending), starting strictly after q.After; filled like GetUnit. Unknown or tombstoned bank =
	// domain.ErrNotFound.
	ListUnits(ctx context.Context, q UnitQuery) ([]domain.Unit, error)
	// ObservationHistory returns the observation_versions rows of observation id, newest first; unknown id
	// or unknown / tombstoned bank = domain.ErrNotFound.
	ObservationHistory(ctx context.Context, b BankRef, id UnitID) ([]domain.ObservationVersion, error)
	// BankStats returns b's counts from indexed COUNT queries; unknown or tombstoned bank =
	// domain.ErrNotFound.
	BankStats(ctx context.Context, b BankRef) (domain.BankStats, error)
	// TagCounts returns up to limit tags of b's source with their counts, ordered by tag, keeping tags that
	// start with prefix and sort after after ("" = from the start). Source unspecified = memories (live
	// units). Unknown or tombstoned bank = domain.ErrNotFound.
	TagCounts(
		ctx context.Context, b BankRef, source domain.TagSource, prefix, after string, limit int,
	) ([]domain.TagCount, error)
	// ListDocuments returns up to q.Limit documents matching q, newest first (created_at, then id, both
	// descending), starting strictly after q.After, with UnitCount and UnitsByFactType filled. Unknown or
	// tombstoned bank = domain.ErrNotFound.
	ListDocuments(ctx context.Context, q DocumentQuery) ([]domain.Document, error)
	// ListScopes returns up to limit of b's observation scopes (every scope holding an observation or an
	// unconsolidated unit) with their counts, ordered by ScopeKey.String(), starting strictly after after
	// ("" = from the start). Unknown or tombstoned bank = domain.ErrNotFound.
	ListScopes(ctx context.Context, b BankRef, after string, limit int) ([]domain.ScopeInfo, error)
	// MentalModelSpecs returns the spec of every mental model of b, ordered by id. Unknown or tombstoned
	// bank = domain.ErrNotFound.
	MentalModelSpecs(ctx context.Context, b BankRef) ([]domain.MentalModelSpec, error)
	// ModelsCiting returns the ids of b's mental models whose source_ids include any of ids, ordered by id.
	// Unknown or tombstoned bank = domain.ErrNotFound.
	ModelsCiting(ctx context.Context, b BankRef, ids []UnitID) ([]MentalModelID, error)
	// BanksToConsolidate returns every bank that is not tombstoned and has at least one live unit with
	// consolidated_at and consolidation_failed_at unset (worker.ConsolidationCandidates).
	BanksToConsolidate(ctx context.Context) ([]BankRef, error)
```

### `internal/port/queries.go` (new types, moved verbatim from the engine packages)
- `UnitQuery` and `UnitCursor` from `internal/engine/curate/lister.go` (fields: Bank, Types, Q, DocumentID,
  EntityID, State, Start, End, TimeField, Tags, TagsMatch, After *UnitCursor, Limit; cursor: CreatedAt, ID).
- `DocumentQuery` and `DocumentCursor` from `internal/engine/docs/documents.go` (fields: Bank, Q, Tags,
  TagsMatch, Start, End, TimeField, After *DocumentCursor, Limit; cursor: CreatedAt, ID).

Semantics to pin in the contract suite (internal/porttest): a tombstoned bank reads NotFound on all of the
above; `EntityID` matches live units only; a null timestamp never matches a bound on it; Tags use
`domain.MatchTags`; `ListUnits` with State unspecified returns both tables interleaved in one order.
