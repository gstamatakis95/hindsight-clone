# CCR WP-12-1 — Mental-model reads: in-scope newest seq, model listing, cron models, failed refreshes

**Status: PROPOSED** (WP-12). The engine already consumes these through interfaces it declares in
`internal/engine/mentalmodel/reads.go` (`ScopeReader`, `ModelLister`, `CronSource`, `FailureSource`), tested
with stubs over `internal/fake`. Nothing in `internal/port` was edited.

## Problem
The mental-model engine needs four reads the ports don't have:

1. **Staleness and the no-LLM check.** SPEC Behavioural rules: "a model is stale if a unit or observation
   with seq above `last_seq_seen` matches its own scope (tags, tag groups, fact types)", and "If nothing is
   in scope or in the window, the refresh completes with no LLM call". The Reader's searches need a query
   text or vector; nothing answers "is there any live unit in this scope with seq in (a, b]?".
2. **Listing models.** ListMentalModels (folder prefix, tags, paging), DeleteFolder (recursive), the
   refresh-after-consolidation trigger and SearchPages all list a bank's models. `MentalModelRepo` only has
   `Get` (decision 601 already flagged ListMentalModels and DeleteFolder).
3. **Cron.** `worker.CronRefresher` must find every model with `refresh_cron` across banks and key
   due-ness on its newest refresh operation's `created_at` (WP-05 doc). There is no cross-bank read.
4. **Failure reconcile.** `worker.RefreshFailureReconciler` (SPEC 2003, decision 012 R10') keys on "the
   latest *terminal* refresh_mental_model operation per model". `Queue.List` is per bank and has no
   per-serial-key "latest terminal" view.

## Proposed diff (`internal/port`)

```diff
 // queries.go
+// ScopeQuery selects the live units (facts and observations) of one bank in a model's scope.
+type ScopeQuery struct {
+	// Bank is the bank searched.
+	Bank BankRef
+	// Types limits fact types; empty = all.
+	Types []domain.FactType
+	// Tags filters by tags; nil = no filter.
+	Tags *SQLPredicate
+	// Seq bounds the units' seq.
+	Seq SeqRange
+}
+
+// ModelQuery selects mental models of one bank for listing.
+type ModelQuery struct {
+	// Bank is the bank listed.
+	Bank BankRef
+	// FolderPrefix keeps models whose folder_path equals it or lies under it ("a" matches "a" and "a/b",
+	// not "ab"); empty = all.
+	FolderPrefix string
+	// Tags filters by model tags with domain.MatchTags semantics; empty = no filter.
+	Tags []string
+	// TagsMatch is how Tags compare.
+	TagsMatch domain.TagsMatch
+	// RefreshAfterConsolidation keeps only models whose trigger sets refresh_after_consolidation.
+	RefreshAfterConsolidation bool
+	// PageSize caps the page; 0 = all.
+	PageSize int
+	// PageToken continues a previous listing; empty = first page.
+	PageToken string
+}
+
+// CronModel is a model with a refresh_cron schedule.
+type CronModel struct {
+	// Model is the model.
+	Model domain.MentalModel
+	// LastRefreshEnqueuedAt is the created_at of the model's newest refresh_mental_model operation (any
+	// status); zero when it has none.
+	LastRefreshEnqueuedAt time.Time
+}
+
+// FailedRefresh is a model whose latest terminal refresh_mental_model operation is FAILED.
+type FailedRefresh struct {
+	Bank        BankRef
+	ModelID     MentalModelID
+	OperationID OperationID
+	// FailedAt is the operation's finished_at.
+	FailedAt time.Time
+	// Error is the operation's recorded error.
+	Error string
+}

 // store.go, Reader
+	// NewestSeqInScope returns the highest seq of a live unit matching q, or 0 when none matches.
+	NewestSeqInScope(ctx context.Context, q ScopeQuery) (int64, error)
+	// ListMentalModels returns one page of q.Bank's models ordered by id (with content) and the next
+	// page token ("" = last page).
+	ListMentalModels(ctx context.Context, q ModelQuery) ([]domain.MentalModel, string, error)
+	// CronModels returns every model with refresh_cron set whose bank is not tombstoned (cross-bank;
+	// maintenance only).
+	CronModels(ctx context.Context) ([]CronModel, error)
+	// FailedRefreshes returns, per model, its latest terminal refresh_mental_model operation when that
+	// operation is FAILED, for models that exist on banks that are not tombstoned (cross-bank; maintenance
+	// only).
+	FailedRefreshes(ctx context.Context) ([]FailedRefresh, error)
```

The engine's `reads.go` types become aliases of these (`type ScopeQuery = port.ScopeQuery`, ...) and its
interfaces are satisfied by `port.Reader`, so WP-14 wires `store.Read()` for all four.

### Postgres sketch
- `NewestSeqInScope`: `SELECT coalesce(max(seq), 0) FROM memory_units WHERE tenant_id, bank_id AND
  fact_type = ANY($types) AND seq > $after AND seq <= $upto AND <predicate over tags>` (reuses the recall
  arms' predicate rendering; the `(tenant_id, bank_id, seq)` index if one exists, else the bank index).
- `ListMentalModels`: keyset on `id`; folder prefix as `folder_path = $p OR folder_path LIKE $p || '/%'`
  (escape `%` and `_`); tags via the existing GIN index.
- `CronModels`: `mental_models_refresh_cron_idx`, `LEFT JOIN LATERAL (SELECT max(created_at) FROM operations
  WHERE kind = 'refresh_mental_model' AND serial_key = 'mm:' || m.id AND same bank)`, banks with
  `deleting_at IS NULL`. The adapter already mirrors `trigger.refresh_cron` into the column.
- `FailedRefreshes`: `SELECT DISTINCT ON (tenant_id, bank_id, serial_key) ... FROM operations WHERE
  kind = 'refresh_mental_model' AND status IN ('completed','failed','cancelled') ORDER BY tenant_id,
  bank_id, serial_key, finished_at DESC`, keep `status = 'failed'`, join `mental_models` on
  `id = substr(serial_key, 4)`, banks not deleting.

The fake implements the same over its state; `internal/porttest` gets one suite per method (tenant
isolation, seq bounds, folder-prefix boundary, latest-terminal selection with a newer pending row).
