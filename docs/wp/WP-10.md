# WP-10 plan — Consolidation engine

Owns `internal/engine/consolidate/**`. Depends on WP-02 (fakes) and WP-04 (config, routing, prompts).

## Files
- `doc.go` — package doc.
- `consolidator.go` — `Consolidator`, `ConsolidationResult`, `ConsolidatorDeps`, `NewConsolidator`, `Run`.
- `plan.go` — the read transaction: unconsolidated units, their scopes (ScopeExpander), already-cited scopes.
- `batch.go` — LLM batches, halving, parking, stamping.
- `decide.go` — related observations, CONSOLIDATE prompt and per-call schema, embeddings, dedup (no tx).
- `apply.go` — one short tx per batch: observations, evidence with exact quotes, observation_versions,
  stamps.
- `finish.go` — final tx: leftover stamps, continuation (`More`), refresh triggers, lifecycle event.
- `dedup.go` — `Deduper` (cosine probe + DEDUP_CHECK), `NewDeduper`.
- `scopes.go` — `ScopeExpander`, `NewScopeExpander`, `combinations`.
- `strategy.go` — `StrategyMatcher`, `NewStrategyMatcher`, `Match`, `Preview`.
- `invalidate.go` — `Invalidator`, `NewInvalidator`.
- `payload.go` — the consolidate job payload and `NewJob`.
- `extras.go` — consumer-declared reads/writes the frozen ports lack (CCR WP-10-1) and `Checkpointer`.

## Interfaces implemented
`Consolidator`, `Deduper`, `ScopeExpander`, `StrategyMatcher`, `Invalidator` (all in this package), each with
`var _ Iface = (*impl)(nil)`. `StrategyMatcher` also satisfies `config.StrategyMatcher`.

## Acceptance tests
| Card item | Test |
|---|---|
| A unit in 3 scopes, killed after scope 2, then replayed: no duplicate observations, stamped once | `TestRunReplayAfterKillAtThirdScope` |
| Halving down to a single poison unit | `TestRunHalvesDownToPoisonUnit` |
| Continuation at the cap | `TestRunContinuationAtCap` |
| A strategy overriding the bank but not the request | `TestRunStrategyOverridesBankNotRequest` |
| The dedup merge and keep paths | `TestRunDedupMerge`, `TestRunDedupKeep` |
| Every scope mode expands correctly | `TestScopeExpanderModes`, `TestCombinations` |

Supporting tests: observation versions and evidence quotes on create/update
(`TestRunCreateAndUpdateWriteVersionsAndEvidence`), the per-scope cap (`TestRunObservationCap`),
per-call schema injection (`TestConsolidateSchemaInjection`), outage does not park (`TestRunOutageDoesNotPark`),
refresh triggers (`TestRunTriggersRefreshes`), empty payload / disabled observations, strategy matching and
preview, invalidator methods.
