# WP-01 plan: Postgres adapter

Owns `internal/adapter/postgres/**`. Implements `port.Store` (with `Tx`, `Reader` and every repository) and
`port.Claimer` over pgx v5 and sqlc, against the frozen schema (`schema/schema.sql`, Alembic-owned).

## Files

| File | Contents |
|---|---|
| `store.go` | `Store` (`New`, `Open`, `InTx` at READ COMMITTED, `Read`), `tx` (`Seq`: one `UPDATE banks SET change_seq = change_seq + 1 ... RETURNING` per tx per bank, row lock held to commit; repo accessors) |
| `reader.go` | `reader` (pool- or tx-backed), `GetUnits`, `BankSeq`, `inReadTx` for transaction-local settings |
| `search.go`, `predicate.go` | `SearchVector` (HNSW, `ef_search = 200`, `iterative_scan = strict_order`, `max_scan_tuples`), `SearchText` (pg_search BM25), `SearchTemporal`, `ExpandGraph` (recursive CTE capped by hops); `SQLPredicate` rendered to one WHERE fragment |
| `bank.go`, `bank_delete.go` | `BankRepo` (Get, Ensure, Create, SetConfig, MarkDeleting, tenant config; DeleteBatch, Delete) |
| `units.go`, `entities.go`, `links.go`, `evidence.go` | `UnitRepo`, `EntityRepo`, `LinkRepo`, `EvidenceRepo` |
| `documents.go`, `chunks.go`, `mentalmodels.go`, `directives.go`, `events.go` | the remaining repositories |
| `queue.go` | `Queue`: Enqueue (three dedupe policies via `joinable`, bank `FOR KEY SHARE`, advisory lock in its own statement, joined row `FOR UPDATE`), Upgrade, Reschedule, CancelBank, Get, List, Cancel, Retry, Prune |
| `claimer.go` | `Claimer` on `*Store`: the spec's claim SQL verbatim + processing update, retried on unique violation; Heartbeat, Progress, Alive, Complete, Fail, ReclaimStale |
| `errors.go`, `convert.go` | driver error -> domain error mapping; row <-> domain conversions |
| `queries/*.sql`, `db/` | sqlc queries (one file per area) and generated code |
| `pgtest/` | test harness: one ParadeDB testcontainer per test binary (same image as compose, bootstrap hidden), migrated by the repo's Alembic, truncated per test |

Interfaces implemented (compile-time asserted): `port.Store`, `port.Tx`, `port.Reader`, `port.Claimer`,
`port.Queue`, `port.BankRepo`, `port.DocumentRepo`, `port.ChunkRepo`, `port.UnitRepo`, `port.EntityRepo`,
`port.LinkRepo`, `port.EvidenceRepo`, `port.MentalModelRepo`, `port.DirectiveRepo`, `port.EventRepo`.

## Acceptance tests

| Card item | Test |
|---|---|
| Every porttest suite passes on testcontainers Postgres (same image as compose) | `TestStoreContract` (RunStoreSuite), `TestSeqContract` (RunSeqSuite), `TestQueueContract` (RunQueueSuite) in `contract_test.go` |
| Serial keys: 8 goroutines claiming 500 jobs over 20 serial keys never hold two PROCESSING rows for one key | `TestAcceptSerialKeys` (`queue_accept_test.go`) |
| Seq order: later commit has the higher seq; a reader seeing S sees every row <= S | `TestAcceptSeqOrder` (`seq_accept_test.go`) |
| Small banks: a bank holding 0.1% of 50k rows still gets 10 semantic hits | `TestAcceptSmallBankVector` (`search_accept_test.go`) |
| Reclaim: a stale heartbeat is reclaimed, and the job fails after max attempts | `TestAcceptReclaim` (`queue_accept_test.go`) |
| Carried forward: porttest gaps (tenant isolation on round 1/2 write ports, Fail(cause, retryAt) on a cancel-requested row, Fail(nil) on a tombstoned bank, Enqueue-join + Upgrade with a concurrent claimer) | new suites `porttest.RunStoreGapsSuite` (`TestStoreGapsContract`) and `porttest.RunQueueGapsSuite` (`TestQueueGapsContract`) |
| Carried forward: adapter obligations (READ COMMITTED, advisory lock before lookup, joined row FOR UPDATE, bank FOR KEY SHARE) | exercised by the queue suites above (concurrent enqueue / upgrade / claim cases) |
