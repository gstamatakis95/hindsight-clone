| Package | Files | Role |
|---|---|---|
| `eval/harness` | `doc.go types.go target.go judge.go clock.go runner.go report.go markdown.go filter.go`, tests `runner_test.go e2e_test.go` | Dataset-neutral types, the `Target` and `Judge` interfaces, the runner (one bank per conversation, sync retain, barrier, recall/reflect, judge) and the report (JSON + Markdown) |

| `eval/locomo` | `doc.go load.go load_test.go testdata/` | LoCoMo loader (one conversation per sample, adversarial category skipped) |
| `eval/golden` | `doc.go golden.go golden_test.go *.yaml` | Golden retain -> recall fixtures and their loader |

## Interfaces implemented

- `harness.Target`: `target.Memd` (gRPC), `target.Hindsight` (HTTP).
- `harness.Judge`: `judge.LLM` (gateway), `judge.Contains` (golden, deterministic).
- `harness.Clock`: `harness.SystemClock`.
- `memoryv1.MemoryServiceServer`, `BankServiceServer`, `OperationServiceServer`: `stub.Server`.

## Acceptance tests

| Card item | Test |
