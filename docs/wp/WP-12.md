# WP-12 · Mental model engine — plan

Owns `internal/engine/mentalmodel/**`. Builds on WP-02 (fakes) and WP-04 (config, routing, prompts).

## Files
| File | What |
|---|---|
| `doc.go` | package overview |
| `reads.go` | consumer-declared reads the ports lack: `ScopeReader`, `ModelLister`, `CronSource`, `FailureSource` (CCR WP-12-1) |
| `scope.go` | resolved scope (defaults, tag groups) and its `port.SQLPredicate` (staleness excludes untagged units) |
| `detect.go` | `ChangeDetector` (`NewChangeDetector`), `isStale`, retracted sources |
| `markdown.go` | sections and blocks with content-derived ids, `applyEdits`, `ApplyEdits`, `ErrAllOpsRejected` |
| `diff.go` | `diffMarkdown` (unified diff for dry run) |
| `planner.go` | MENTAL_MODEL_DELTA call with the reject-and-retry-once rule; `ModelDeps`, `DirectiveSelector` |
| `single_shot.go` | `NewSingleShotSynthesizer` (recall, then SYNTHESIZE or MENTAL_MODEL_DELTA); `Recaller` |
| `agentic.go` | `NewAgenticSynthesizer` (reflect loop as a document; delta integrates its evidence); `Reflector` |
| `refresher.go` | `RefreshRunner`, `Synthesizer`, `Draft`, `DeltaDraft`, `Projector`, fallback reasons |
| `runner.go`, `write.go` | `NewRefreshRunner`: plan, no-LLM check, draft, project, embed, short write tx |
| `scheduler.go` | `RefreshScheduler` (`NewRefreshScheduler`), `EnqueueRefresh`, `RefreshPayload`, `SerialKey` |
| `triggers.go` | `Triggers`: after consolidation, retracted sources, cron (`worker.CronRefresher`) |
| `reconcile.go` | `RefreshFailureReconciler` (`worker.RefreshFailureReconciler`), `RunJob` |
| `admin.go` | `Admin` (mirrors `server.MentalModelAdmin`): CRUD, refresh, clear, history, folders |
| `pages.go` | `PageSearcher` (`NewPageSearcher`) |

## Interfaces implemented
`ChangeDetector`, `Synthesizer` (x2), `RefreshRunner`, `RefreshScheduler`, `Triggers` (structurally
`worker.CronRefresher`), `RefreshFailureReconciler` (structurally `worker.RefreshFailureReconciler`),
`Admin` (mirror of `server.MentalModelAdmin`, decision 1205), `PageSearcher`.

## Acceptance tests
| Card "Accept" | Test |
|---|---|
| A late-committing writer is picked up by the next refresh | `TestLateCommittingWriterPickedUpByNextRefresh` |
| An untagged write never stales a tagged model | `TestUntaggedWriteNeverStalesTaggedModel` |
| A delta with all ops rejected keeps the document | `TestDeltaAllOpsRejectedKeepsDocument` (both strategies), `TestApplyEditsAllRejectedAndEmpty` |
| Nothing in scope means no LLM call | `TestNothingInScopeMeansNoLLMCall` (both strategies) |
| Pause and manual unpause | `TestPauseAndManualUnpause` |
| Joining a queued refresh with `force_full` upgrades it | `TestJoiningQueuedRefreshWithForceFullUpgrades` |
| Both strategies produce a version through the same runner | `TestBothStrategiesProduceVersionThroughRunner` |
