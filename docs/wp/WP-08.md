# WP-08 · Retain engine — plan

Owns `internal/engine/retain/**`. Builds on WP-02 (fakes) and WP-04 (prompts, timex, routing).

## Files

| File | What |
|---|---|
| `ingestor.go` | `Ingestor` + `NewIngestor(IngestorDeps)`: validate, fan-out check, no-op check, blobs, upsert, inline or enqueue |
| `payload.go` | `DocumentPayload` (the `retain_document` job payload), hashing helpers |
| `retainer.go` | `Retainer` + `NewRetainer(RetainerDeps)`: the `retain_document` handler |
| `retainer_write.go` | the per-batch and final transactions (replace, chunks, units, entities, labels, links, complete) |
| `chunker.go` | `Chunk`, `ChunkWith`, `ApproxTokens`: token-budgeted chunking that keeps JSON turns and JSONL lines whole |
| `extractor.go`, `modes.go` | `Extractor`, `ExtractionStrategy`, `Concise/Verbose/Verbatim/Chunks/Custom`, response parsing |
| `resolver.go` | `EntityResolver` + `NewEntityResolver`: trigram + co-occurrence + temporal scoring |
| `labels.go` | `LabelResolver` + `NewLabelResolver`: exact-match label entities, `write_to_tags` |
| `linker.go` | `Linker` + `NewLinker`: temporal, semantic, causal edges within per-unit caps |
| `deps.go` | consumer-declared interfaces (`DateNormalizer`, `ScopeExpander`, `Checkpoint`) and tuning defaults |

## Interfaces implemented

`Ingestor`, `Retainer`, `Extractor`, `ExtractionStrategy` (5 modes), `EntityResolver`, `LabelResolver`, `Linker`,
each with `var _ Iface = (*impl)(nil)`.

Consumed (consumer-declared, producer's exact signatures): `DateNormalizer` (timex.TimeNormalizer.Normalize),
`ScopeExpander` (consolidate.ScopeExpander), `Checkpoint` (worker.Checkpoint), `TokenCounter`.

## Acceptance tests

| Card item | Test |
|---|---|
| An unchanged re-retain makes zero LLM calls | `TestIngestUnchangedMakesNoLLMCall` |
| A crash after chunk 3 of 6, then retry, re-extracts only chunks 4–6 | `TestRetainResumeAfterCrashReextractsOnlyRemainingChunks` |
| Data-loss trap: re-retain of a changed doc, crash midway, resume | `TestRetainChangedDocumentCrashResumeKeepsAllFacts`, `TestRetainForceReextractCrashResume` |
| Replacement deletes the old units' observations and resets their co-sources | `TestRetainReplacementDeletesObservationsAndResetsCoSources` |
| Fan-out rejection stores nothing | `TestIngestFanOutRejectionStoresNothing` |
| Timeless and timestamp handling | `TestRetainTimelessAndTimestamp` |
| Entity merge versus split cases | `TestEntityResolverMergeVersusSplit` |
| Link caps hold | `TestLinkerCapsHold` |
| who/where/why vs ExtractedFact (CCR if needed) | folded into text like Hindsight: `TestExtractorComposesDimensions` (no CCR) |

Supporting tests: chunker (`TestChunk*`), extraction modes (`TestExtractorChunksModeNoCall`,
`TestExtractorVerbatimUsesChunkText`, `TestExtractorFactTypeBySpeaker`), labels (`TestLabelResolver*`),
async path (`TestIngestAsyncEnqueuesChildrenUnderBatch`), consolidate enqueue (`TestRetainEnqueuesConsolidate*`),
seq stamping (`TestRetainStampsSeq`).
