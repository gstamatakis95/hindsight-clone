# WP-03 · Gateway and S3 adapters — plan

Owns `internal/adapter/gateway/**` and `internal/adapter/s3/**`. Reads: SPEC "Model routing", "Ports"
(models, blobs), "Code standards", "Behavioural rules".

## Files

`internal/adapter/gateway/`

| File | Contents |
|---|---|
| `doc.go` | package doc (exists) |
| `client.go` | `Config`, `NewClient`, `Client`, the shared `do` loop: semaphores, per-attempt timeout, retry with backoff, error mapping, usage hook |
| `limits.go` | `limiter`: process-wide semaphore plus optional per-slot semaphores (slot first, then global) |
| `chat.go` | `Structured` (response_format json_schema, validate, retry with the error) and `Chat` (tools) |
| `embeddings.go` | `EmbedDocuments` / `EmbedQuery`: nomic prefixes, batching, reorder by index, 768-dim check |
| `rerank.go` | `Rerank`: Cohere/Jina body, reorder by index, [0,1] pass-through else sigmoid |
| `schema.go` | a small JSON Schema validator (the subset in decision 303) |
| `*_test.go` | `httptest` gateway emulating `/v1/chat/completions`, `/v1/embeddings`, `/v1/rerank` |

`internal/adapter/s3/`

| File | Contents |
|---|---|
| `doc.go` | package doc (exists) |
| `blob.go` | `Config`, `NewBlob`, `Blob` over aws-sdk-go-v2; `DeletePrefix` = ListObjectsV2 + DeleteObjects per page |
| `blob_test.go` | MinIO testcontainer (one per test binary), `porttest.RunBlobSuite`, 2,500-key DeletePrefix |

## Interfaces implemented

- `*gateway.Client`: `port.LLM`, `port.Embedder`, `port.Reranker` (compile-time assertions in client.go).
- `*s3.Blob`: `port.Blob` (assertion in blob.go).
