## Interfaces declared
- **Ports:** every interface in the spec's Ports block: Store, Tx, Reader, UnitRepo, DocumentRepo,
  ChunkRepo, EntityRepo, LinkRepo, EvidenceRepo, EventRepo, Queue, Claimer, Blob, LLM, Embedder, Reranker,
  ModelRouter, ConfigResolver and Clock.
  - Also BankRepo and MentalModelRepo, which the spec references but never defines (decision 005).
- **Engines:** every interface in the Engines blocks, each in its own engine package. No
  implementations; Phase 2 implements them.

## Acceptance checks → how they are verified

| Card "Accept" item | Check (test / command) |
|---|---|
| `make gen && make lint` pass and `go build ./...` succeeds | `make gen && make lint && go build ./...`; `git status --porcelain gen schema internal/mocks` empty after `make gen` |
| `buf lint` passes with STANDARD + COMMENTS | `buf lint` (inside `make lint-proto`); descriptor comparison spec-vs-split identical (decision 002) |
| `alembic upgrade head` then `downgrade base` succeed on the compose Postgres | `make up && make migrate && make downgrade && make migrate` |
| schema.sql diff check is clean | `make migrate-check` (`scripts/schema-check.sh`) |
| porttest suites compile; skips name the implementing WP | `go vet ./internal/porttest/` and `go test -v ./internal/porttest/`: `TestStoreSuitePostgres`, `TestStoreSuiteFake`, `TestSeqSuitePostgres`, `TestSeqSuiteFake`, `TestQueueSuitePostgres`, `TestQueueSuiteFake`, `TestBlobSuiteS3`, `TestBlobSuiteFake` each skip with "pending WP-0n" |
| Tag the merge commit `contracts-v1` | Done by the orchestrator on merge |
