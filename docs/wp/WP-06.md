# WP-06 · Server shell — plan

Branch `wp/WP-06-server-shell`. Owns `internal/server/**`. The handlers are thin. Each one checks the tenant
and ids, converts the proto to domain types, calls one engine or consumer interface, converts the result
back and maps the error with `toStatus`.

## Files

| File | What |
|---|---|
| `deps.go` | `Deps` (every engine interface plus the server-declared consumer interfaces) and the consumer interfaces with their request and page types |
| `handler.go` | `notWired`, `Deps.validate` |
| `server.go` | `New(d Deps, opts...)`: registers all eight `memory.v1` services and `grpc.health.v1`, and chains the interceptors |
| `interceptors.go` | `TenantInterceptor`, `DeadlineInterceptor`, `TenantFrom`, id checks |
| `status.go` | `toStatus`: domain error to gRPC status |
| `health.go` | Health server whose `Check` runs the readiness probes (Postgres, gateway) |
| `convert_enum.go` | Descriptor-driven enum conversion, timestamps, int clamping, optional helpers |
| `convert_common.go`, `convert_config.go`, `convert_fieldmask.go`, `convert_memory.go`, `convert_memories.go`, `convert_bank.go`, `convert_document.go`, `convert_observation.go`, `convert_mental_model.go`, `convert_operation.go` | proto ↔ domain for every message, and FieldMask patches |
| `svc_*.go` | One server type per service |

## Interfaces consumed
- **Engines.** `retain.Ingestor`, `recall.Recaller`, `reflect.Reflector`, `curate.MemoryLister`,
  `curate.Curator`, `bank.StatsReader`, `bank.PromptPreviewer`, `bank.BankDeleter`, `bank.TemplateCodec`,
  `docs.Retagger`, `consolidate.StrategyMatcher`, `mentalmodel.RefreshRunner`, `mentalmodel.PageSearcher`,
  `worker.OperationControl` and `port.ConfigResolver`.
- **Server-declared consumer interfaces**, for RPCs that no engine interface covers (decision 601):
  `TenantAdmin`, `BankAdmin`, `DirectiveAdmin`, `DocumentAdmin`, `ObservationAdmin`, `MentalModelAdmin`,
  `OperationReader` and `ReadinessProbe`.

## Interfaces implemented
- `memoryv1.{Memory,MemoryUnit,Tenant,Bank,Document,Observation,MentalModel,Operation}ServiceServer`.
- `grpc_health_v1.HealthServer`.
