# WP-11 — Reflect engine: plan

Owns `internal/engine/reflect/**`. Builds on WP-02 (fakes) and WP-04 (config, routing, prompts).

## Files
- `reflector.go` — request/result types (existing), `ReflectorDeps`, `NewReflector`, `Reflect` (validate, resolve
  config, read directives and bank name, run the loop, citations, structured pass, trace and usage).
- `loop.go` — the agent loop: iteration cap, tool dispatch, evidence guard, closing `done` turn, final synthesis,
  context-overflow fallback, token budget.
- `tools.go` — `Tool`, `ToolResult`, `AgentState`, `PageReader` (existing) plus the consumer-declared `ChunkReader`.
- `tools_impl.go` — `DefaultTools`: search_mental_models, read_mental_models, search_observations, recall, expand
  (`done` is handled by the loop, its schema comes from `prompts.JSON` / `prompts.DoneTool`).
- `citations.go` — `validCitations` and BasedOn assembly.
- `directives.go` — directive selection by tags (`apply_all`, extras appended).
- `prompt.go` — `PromptBuilder` (`NewPromptBuilder`) over the effective config, with disposition.
- `structured.go` — `StructuredProjector` (`NewStructuredProjector`) and the unexported `project` that also
  returns usage.
- `document.go` — renders the document-mode `done` argument to markdown.
- `usage.go` — per-(slot, model) usage aggregation and the max_total_tokens check.

## Interfaces implemented
`Reflector`, `Tool` (5 retrieval tools), `PromptBuilder`, `StructuredProjector`. Consumed: `Recaller`
(recall.Recaller subset), `PageReader` (mentalmodel provides), `ChunkReader` (CCR WP-11-2), `port.Store`,
`port.Reader`, `port.ConfigResolver`, `port.ModelRouter`, `port.LLM`, `port.Clock`.
