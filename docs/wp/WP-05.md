# WP-05 · Worker runtime — plan

Branch `wp/WP-05-worker-runtime`. Owns `internal/worker/**` (plus its generated mocks in
`internal/mocks/worker`). Reads: SPEC "Jobs", "Behavioural rules" (operations), "Function signatures"
(worker), decision 012 (R7, R8', R10').

## Files

| File | Contents |
|---|---|
| `errors.go` | `ErrPermanent`, `ErrRetryAt` (type) and `RetryAt(at, cause)` |
| `retry.go` | retry policy: 60 s × attempt with the per-kind cap (`domain.OperationKind.MaxAttempts`), consolidate capped exponential backoff, skip-if-pending |
| `runner.go` | `JobRunner` interface, `Runner`, `RunnerConfig`, `Handler`, `NewRunner`, `Handle`, `Run` (poll, slots, dispatch) |
| `exec.go` | one job's life: invoke with panic recovery, settle via Complete/Fail, heartbeats and lost jobs |
| `result.go` | `ReportResult(ctx, result, usage)`: a handler hands its result and usage to the runner's Complete |
| `pending.go` | `PendingChecker` + `NewPendingChecker(port.Store)` (Queue.List over pending consolidate) |
| `checkpoint.go` | `Checkpoint` (frozen by WP-00) + `NewCheckpoint(port.Claimer, port.OperationID)` |
| `control.go` | `OperationControl` (frozen by WP-00) + `NewOperationControl(port.Store)` |
| `maintenance.go` | `MaintenanceDeps`, `RunMaintenance`, consumer interfaces `ConsolidationCandidates`, `CronRefresher`, `RefreshFailureReconciler`, `PruneOperations` |

| `*_test.go` | in-package tests with a test-local fake Claimer/Queue/Store and Clock (`fake_test.go`) |

## Interfaces implemented
- `worker.JobRunner` by `*Runner`; `worker.Checkpoint` by `*checkpoint`; `worker.OperationControl` by
  `*operationControl`; `worker.PendingChecker` by `*pendingChecker`.
- Consumes `port.Claimer`, `port.Store` (Tx.Queue, Tx.Events), `port.Clock`.
- Declares for later WPs: `ConsolidationCandidates` (WP-01/WP-10, a CCR'd read or adapter query),
  `CronRefresher` and `RefreshFailureReconciler` (WP-12).
